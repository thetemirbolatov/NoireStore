**Noire Store** — минималистичный магазин приложений и игр для Android, выполненный в глубокой монохромной OLED-палитре.

---

###  Основные возможности

- **Строгий OLED-дизайн** — интерфейс на базе чисто чёрного цвета (`#000000`) с серебристыми акцентами, без лишней рекламы и визуального шума.
- **Умный и голосовой поиск** — мгновенный поиск приложений по названию, категориям и описанию, а также встроенный голосовой ввод.
- **Фоновые загрузки** — скачивание APK с отображением прогресса в шторке уведомлений и автоматической очисткой кэша.
- **Оценки и отзывы** — просмотр реального рейтинга приложений и быстрая отправка отзывов разработчику.
- **Самообновление** — встроенная проверка новых версий самого магазина и уведомления о выходе свежих релизов.

---

###  Установка

1. Перейдите в раздел **[Releases](../../releases/latest)**.
2. Скачайте актуальный файл **`noire-store.apk`**.
3. Откройте скачанный файл на Android-устройстве и разрешите установку из этого источника.
